Luminous Blog is a modern, elegant WordPress theme built for contemporary bloggers and content creators. With a sophisticated design system, advanced customization options, and optimized performance, it delivers an exceptional reading experience.

== Features ==
* Fully Responsive Design
* Fast & Optimized Performance
* Customizable Colors & Typography
* Blog, Archive & Single Post Templates
* Author Bio & Social Links
* SEO Optimized
* Accessibility Ready (WCAG 2.1)
* Translation Ready
* Dark Mode Support
* Search Functionality
* Widget Areas
* Gutenberg Compatible

== Installation ==
1. Upload 'luminous-blog' folder to wp-content/themes directory
2. Activate the theme in WordPress admin dashboard
